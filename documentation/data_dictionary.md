# Data dictionary

| Object | Purpose |
|---|---|
| CUSTOMER | Customer master used by all banking products. |
| ACCOUNT | Deposit/current account balances and status. |
| LOAN | Loan exposure and maturity details. |
| DEPOSIT | Term-deposit liabilities. |
| BANK_TRANSACTION | Cash movements used for liquidity inflow/outflow. |
| LIQUIDITY_REPORT | Calculated ALM output. |
| DATA_LINEAGE | Column-level dependency and transformation metadata. |
| REPORT_METRIC | Business definition of the report metric. |
